# 🧥 HouseWith

> 가족 소통 도움 앱 (SpringBoot & React 팀 프로젝트)

---

## 📌 프로젝트 소개

HouseWith는 "**오늘 우리 가족은 어떤 하루를 보냈을까?**"라는 작은 궁금증에서 시작되었습니다.  

각자의 일상으로 바빠 얼굴 맞대기 힘든 요즘, 억지로 대화를 강요하기보다  
**자연스러운 질문**과 **세심한 안부 확인**을 통해 가족 간의 정서적 거리를 좁혀주는 '**가족 전용 감성 커뮤니티**'입니다.

---

## 🎯 핵심 가치

- 🏠 **정서적 온기**

  → "주간 질문"을 통해 평소 나누지 못했던 속마음을 공유하고, 서로의 생각을 알아가며 가족의 유대감을 쌓습니다.

- 🌱 **세심한 배려와 안부 (Caring & Notice)**

  → 가족 중 누군가의 접속이 뜸해지면 따뜻한 알림을 통해 서로의 안부를 묻게 함으로써, 무관심 속에 방치되는 구성원이 없도록 챙겨줍니다.

- 🤝 **가벼운 일상 분담 (Light Task Sharing)**

  → 거창한 가사 노동이 아닌, "오늘 쓰레기 버리기"처럼 소소한 규칙들을 가볍게 체크하며 서로 돕고 있다는 느낌을 자연스럽게 공유합니다.
